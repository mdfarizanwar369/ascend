# App Store demonstration fixture

`listing-meal.jpg` is generated demonstration content created with the built-in
image-generation tool on 29 September 2026. It is not a customer's photo or a
testimonial. The screenshot workflow passes it through the real food estimate UI;
no nutrition response is mocked or substituted.

Prompt: A realistic smartphone photograph looking down at one white ceramic bowl
containing grilled chicken breast slices, steamed white rice, broccoli and carrot
slices. Simple pale wooden table, soft daylight, everyday home lunch, clear view of
all food, no garnish clutter, no drinks, no hands, no text, no logos, no watermark.
Square composition. Standalone food photograph, not an app screenshot.

Native screen captures use fresh fictional Alex accounts. Their manually logged
history is demonstration data, including constant weight rather than invented
weight-loss outcomes. Capture artifacts contain PNGs only, never auth tokens or
passwords. The simulator-only control helper is not included in release builds.
