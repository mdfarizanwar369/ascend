# Ascend iOS 1.2 App Store copy

## What's New

Trainer Pro is now available to independent trainers. Start from Profile > Subscriptions, choose Independent Trainer or enter a gym invitation, and create a trainer workspace with a referral code for clients. Eligible customers can start the Apple-displayed introductory trial. Clients review the trainer identity and shared coaching information before connecting, and can disconnect at any time.

## Promotional text

Train yourself or coach clients with Ascend. Independent trainers can now create a Trainer Pro workspace directly in the app and invite clients with a referral code.

## App Review notes

Ascend is free to download and offers two optional monthly auto-renewable subscriptions in the Ascend Membership subscription group:

- Ascend Premium: `fit.getascend.app.premium.monthly`
- Trainer Pro: `fit.getascend.app.trainerpro.monthly`

To test the public Trainer Pro flow:

1. Download or open Ascend and create or sign in to an account.
2. Open Profile > Subscriptions.
3. Select Trainer Pro.
4. Choose Independent Trainer. No gym approval or invitation is required.
5. Review the Apple-supplied trial and renewal terms and confirm with Apple's purchase sheet.
6. After server verification, Ascend creates the trainer workspace and referral code automatically.

An eligible Apple customer sees **14 days free, then Apple's localized monthly price**. Customers who are not eligible see the normal Apple-supplied monthly price. Ascend does not decide introductory-offer eligibility.

Trainer Pro includes the trainer's personal Premium features. During the introductory trial, the trainer can connect up to two real clients; the initial paid plan supports five active clients. Demo data does not count toward these limits.

Client connection test:

1. From the trainer dashboard, copy the Trainer Pro referral code.
2. In a separate client account, open Profile and enter the code under Trainer connection.
3. Ascend displays the trainer identity, workspace and data categories before connection.
4. Tap Confirm and connect. The trainer receives access only after this explicit confirmation.
5. The client can end access with Profile > Trainer connection > Disconnect trainer.

Restore Purchases and Manage Apple Subscriptions are available on Profile > Subscriptions. Privacy Policy and Terms of Use links are on the same screen. Apple transaction verification occurs on the Ascend server before access is granted. A Trainer Pro purchase grants only trainer capabilities; it does not grant administrative or owner privileges.
