# Ascend Pilot Guide: Gym Owners

This guide covers the minimum needed to run a controlled pilot at Austin Green and Kulai Indahpura.

## Before Inviting Anyone

1. Log in and confirm **Admin** appears in the bottom navigation.
2. Open **Referrals** and confirm each gym has an active code.
3. Create a trainer referral code only after the trainer is known.
4. Keep the first group small: 1-2 trainers and 5-10 clients per gym.
5. Confirm `support@getascend.fit` receives mail.

## Approve A Trainer

1. Open **Admin > Users**.
2. Find the trainer application.
3. Assign the correct gym and approve the trainer role.
4. Grant Trainer Pro pilot access if required.
5. Ask the trainer to log out and back in once, then confirm the Trainer dashboard opens.

## Assign A Client

1. Open **Admin > Users**.
2. Find the client.
3. Confirm their referral source and gym.
4. Assign the correct trainer. A trainer referral should normally assign that trainer automatically; verify it.
5. Grant Premium pilot access only to approved pilot participants.

## Daily Owner Check

- Review owner notifications.
- Approve legitimate trainer applications.
- Assign unassigned Human Coach clients.
- Check recent AI errors and support requests.
- Do not permanently delete a user while investigating an issue.

## Weekly Owner Review

- Active clients and trainers
- Food, water, weight, and habit participation
- Trainer attention actions and response patterns
- AI usage and estimated cost
- Referral performance
- Qualitative feedback and any support incidents

Use `PILOT_WEEKLY_REVIEW.md` for the meeting.

## Account Cleanup

Deactivate a user first. Permanently delete only confirmed test accounts or departed users after checking that live billing is cancelled and required records no longer need to be retained.

## Support Escalation

For a serious access, privacy, billing, or data issue, pause the affected flow and record the time, account email, device/browser, and screenshot. Do not request or store the user's password.
